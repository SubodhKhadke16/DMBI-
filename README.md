# Student Academic Performance Prediction

This beginner-friendly DMBI mini project uses the official [UCI Student Performance dataset](https://archive.ics.uci.edu/dataset/320/student+performance) to identify students who may need academic support.

## Problem and objective

The system predicts:

- **Pass**: final Mathematics grade `G3 >= 10`
- **At Risk**: final Mathematics grade `G3 < 10`

The model deliberately excludes `G1` and `G2` because they are earlier examination grades, and excludes `G3` because it creates the target. This makes the prediction suitable for an earlier-support scenario.

## Project structure

`src/data_preprocessing.py` contains loading, inspection, target creation, and a leakage-safe `ColumnTransformer`. `src/exploratory_analysis.py` creates the charts. `src/train_models.py` trains all three classifiers. `src/evaluate_models.py` calculates metrics and saves reports. `src/predict_student.py` provides CLI prediction. `app.py` provides the Streamlit dashboard.

## Dataset setup

Download the UCI archive and place the extracted `student-mat.csv` at:

```text
data/raw/student-mat.csv
```

The loader expects a semicolon separator. No fake records or fabricated results are included. The file is not bundled because it is an external dataset.

## Installation on Windows

In PowerShell from the project directory:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, run `Set-ExecutionPolicy -Scope Process Bypass` for the current terminal, or use `.venv\Scripts\python.exe` directly.

## Run the complete pipeline

```powershell
python main.py
```

This prints dimensions, the first five rows, missing-value checks, duplicates, and target distribution; tunes Decision Tree, Random Forest, and Logistic Regression using five-fold stratified cross-validation on the training partition; selects the algorithm and probability threshold using training-only results; evaluates the selected configurations once on the untouched test partition; saves `models/best_model.joblib`; saves `reports/model_comparison.csv`, `reports/cross_validation_results.csv`, `reports/threshold_analysis.csv`, and `reports/test_predictions.csv`; and generates high-resolution figures in `reports/figures/`.

The selected model is chosen from training-only cross-validation using the highest At Risk recall at the selected threshold, with At Risk F1 as the tie-breaker. The held-out test set is not used for tuning or selection. This is a business choice: missing a student who needs support is more concerning than sending a teacher a few extra referrals. Threshold analysis tests 0.30, 0.40, 0.50, 0.60, and 0.70; a lower threshold is not automatically better because the precision/false-positive trade-off must be considered.

Run an interactive command-line prediction after training:

```powershell
python -m src.predict_student
```

## Launch the dashboard

```powershell
streamlit run app.py
```

The dashboard loads the real CSV, saved model, saved metrics, and generated figures. Run `python main.py` first so the model outputs exist.

## Additional generated evidence

The pipeline also creates separate confusion matrices, saved text and JSON classification reports, ROC and precision-recall comparison charts, threshold charts, `models/model_metadata.json` with the dataset hash and environment information, and `logs/project.log`. These outputs contain only values generated by the current execution.

Run automated tests with:

```powershell
python -m pytest -q
```

The tests cover dataset shape and target creation, leakage exclusions, model training, saved-model prediction, and probability validity.

## Preprocessing and algorithms

Numerical values use median imputation and `StandardScaler`. Categorical values use most-frequent imputation and `OneHotEncoder(handle_unknown="ignore")`. These steps are inside a Scikit-learn `Pipeline` and `ColumnTransformer`, so they are fitted only on training data.

The project compares a Decision Tree, Random Forest, and Logistic Regression. It reports accuracy, precision, recall, F1-score, ROC-AUC, confusion matrices, and classification reports, with additional At Risk class metrics.

## Dataset attributes

The UCI file contains school, demographic, family, study, support, attendance, and behavioural variables such as `school`, `sex`, `age`, `studytime`, `failures`, `schoolsup`, `famsup`, `internet`, and `absences`, along with the grade columns. See the UCI source for the authoritative attribute definitions.

## Limitations and future scope

This is a historical observational dataset, so predictions are not causal and should not be used for automatic disciplinary decisions. It is relatively small, may not represent every institution, and contains self-reported variables. Future work could validate on a newer local cohort, calibrate probabilities, monitor fairness across groups, add teacher feedback, and compare time-aware validation strategies.
